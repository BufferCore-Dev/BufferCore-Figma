Help

Short workflow guides for projects, Flavours and initial setup.

Use a Flavour in a project
1
Create or open the project fileEnable the shared BC libraries you need: Elements, Components, Layout, Templates and Pages.
2
Enable the Flavour Foundations libraryUse the client/project Flavour Foundations instead of BC: Foundations.
3
Apply the FlavourFlavours → Apply to Project → choose the Ready Flavour → Apply Flavour.
4
Design normallyShared BC Elements and Components stay linked to the Core libraries. Auto Reconcile remaps new BC Foundation bindings as you add things.
5
After Core library updatesAccept the normal Figma library update. Auto Reconcile handles new bindings while BufferCore is open; use Reconcile as the manual safety check.
Set up a new Flavour
1
Create a dedicated Flavour Foundations fileFor example: BC Flavour: Wallwood.
2
Resolve the FlavourBufferCore → Flavours → Build Foundations Library → choose the Flavour → Resolve.
3
Build into this fileBufferCore creates the full resolved Foundations library for that Flavour.
4
Publish it in FigmaPublish the generated Flavour Foundations library.
5
Check status and RegisterOnce Figma reports the library as published/current, register it. It then appears as a Ready Flavour in project files.
A Flavour only gets its own Foundations library. Elements, Components, Layout, Templates and Pages remain shared.
Initial BufferCore setup
1
Prepare the six shared master filesBC: Foundations, Elements, Components, Layout, Templates and Pages.
2
Build/sync the correct content into each fileUse Settings → Core Setup in the matching master file.
3
Publish each library in FigmaRegistration is blocked until the relevant library is actually published and current.
4
Register each master fileUse Settings → Core Setup to register the matching level after publishing.
